Rouint

CLI-Based API Endpoint Management & Testing Tool Powered by System curl

Rouint is a lightweight, local-first Python CLI application published on PyPI. It replaces bulky GUI API clients with terminal speed and raw curl transparency — allowing software engineers to define API endpoint templates once, switch base URL environments seamlessly, and run interactive API tests with live metrics.

Product Deep-Dive

What makes Rouint different?

Modern API testing applications like Postman, Insomnia, or Bruno have become memory-heavy desktop applications that consume hundreds of megabytes of RAM and require cloud logins for basic collection management. On the other end of the spectrum, standard terminal curl commands are fast but lack endpoint persistence, dynamic parameter substitution, and organized response metrics.

Rouint (pronounced /ruː-ɪnt/) delivers the best of both worlds. It acts as an intelligent wrapper around your system's native curl binary. Rouint stores endpoint templates in a local .rouint-data/ folder within your project repository, allowing you to run, edit, parameterize, and benchmark APIs without leaving your shell prompt.

Key Architectural Innovations

  • 01 // Template Placeholders with Auto-Encoding:
    Define paths such as /api/v1/users/{user_id}/orders/{order_id}. Rouint prompts for inputs dynamically during execution and automatically URL-encodes parameter values.
  • 02 // Interactive 7-Step Wizard with Esc Navigation:
    Build complex endpoints step-by-step (Method, Path, Headers, Auth, JSON Body, File Attachments, Name). Press Esc at any point to step back and revise previous entries without losing context.
  • 03 // Multi-Environment Base URL Switcher:
    Register base URLs for local, staging, and production environments. Endpoint definitions remain decoupled from base URLs, allowing instant environment selection at test time.
  • 04 // Bearer Token Auto-Detection & Reuse:
    When authentication endpoints return JWT/Bearer tokens in response payloads, Rouint automatically detects the token, asks if you want to store it temporarily, and automatically injects it into subsequent Bearer-authenticated requests.
  • 05 // Rich Terminal Visualization & Live Metrics:
    Outputs pretty-printed JSON inside full-width terminal panels for REQUEST, RESPONSE, and real-time METRICS (HTTP Status, Latency in ms, and Response Payload Size).
  • 06 // Local-First Storage & Automatic Git Security:
    All project configurations live locally in .rouint-data/. Rouint automatically writes a .gitignore file inside the folder to ensure tokens, environment URLs, and request bodies are never accidentally committed to git.

CLI Command Reference

Usage & Workflow
1. Initialize Workspace 
$ rouint init

Creates .rouint-data/ in current directory:
├── .gitignore       # Auto-blocks tokens/secrets
├── config.json      # Workspace preferences
├── registry.json    # Maps endpoint IDs to names
├── endpoints/       # Saved endpoint templates
├── environments/    # Base URLs (gitignored)
└── bodies/          # Request JSON bodies (gitignored)
2. Manage Base URLs 
$ rouint add-base-url

Options:
 [1] Add a new base URL
 [2] Delete an existing base URL

Label: local
URL:   http://127.0.0.1:8080

Saved environment 'local' → http://127.0.0.1:8080
3. 7-Step Endpoint Wizard 
$ rouint add-new-api

Wizard Steps (press Esc anytime to go back):
 1. HTTP Method   : POST
 2. Endpoint Path : /api/v1/users/{user_id}
 3. Headers       : Content-Type: application/json
 4. Auth Type     : Bearer Token
 5. Request Body  : {"name": "Kavi", "role": "admin"}
 6. File Attach   : None
 7. Endpoint Name : Create User

Endpoint saved as 'create-user'
4. Run & Benchmark API 
$ rouint start-test

Flow: Endpoint → Base URL → Fill {placeholders} → Run

Frequently Asked Questions

Rouint Knowledge Base

What is Rouint and how does it work?

Rouint is an open-source CLI-based API endpoint management and testing tool published on PyPI (pip install rouint). Created by Kavimugil Rajasekar, Rouint wraps your system's native curl binary to let developers define reusable API endpoint templates, manage environments locally, and execute requests directly from the command line.

How do I install Rouint on Windows, macOS, or Linux?

You can install Rouint on any operating system with Python 3.9+ using PyPI: pip install rouint. Ensure that curl is installed and available on your system's PATH.

Where does Rouint store environment URLs and API tokens?

All configurations are stored locally inside a .rouint-data/ directory inside your project root. Rouint automatically creates a .gitignore inside this folder so that sensitive tokens, base URLs, and request payloads never get committed to source control.

Is Rouint free and open source?

Yes! Rouint is 100% free, open-source software licensed under the MIT license. You can inspect the source code, contribute, or open issues on the official GitHub repository at https://github.com/KavimugilRajasekar/Rouint.
