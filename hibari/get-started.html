Get Started

Run Hibari-Koto1.3.1:29M in Ollama, llama.cpp or the Python engine

Pick the path that fits: Ollama for a quick chat, llama.cpp for a single binary, or the Hibari engine for the full application layer (safety, task router, reply ranking).

1 · Ollama

Quickest 
ollama run kavimugil-r/Hibari-Koto1.3.1:29M

The tag holds the Q8_0 GGUF (29.9 MiB), whose greedy output matched PyTorch on all 11 test prompts. Decoding defaults (temperature 0.5, top-k 25, top-p 0.85, repeat penalty 1.15) and the system prompt come with it.

2 · llama.cpp

One binary 
pip install -U huggingface_hub          # provides the hf command
hf download kavimugil-r/Hibari-Koto Hibari-Koto1.3.1-29M-Q8_0.gguf --local-dir .
llama-cli -m Hibari-Koto1.3.1-29M-Q8_0.gguf --temp 0.5 --top-k 25 --top-p 0.85 --repeat-penalty 1.15 -c 256 \
  -sys "You are Koto, a friendly and calm conversational AI built on the Hibari architecture. Keep replies short, kind and honest."

Other files on Hugging Face: F32 (reference), F16, Q4_K_M (smallest, 17.5 MiB). The chat template is embedded in every GGUF.

3 · Python engine

Full application layer 
git clone --recurse-submodules -b feature/koto-1.3.1 https://github.com/KavimugilRajasekar/Hibari.git
cd Hibari
python -m venv .venv && source .venv/bin/activate        # Windows: .\.venv\Scripts\Activate.ps1
pip install -e .
hf download kavimugil-r/Hibari-Koto --include "pytorch/best_model.pt" --local-dir hf
mkdir -p models/Koto/checkpoints/koto_1.3.1_large
mv hf/pytorch/best_model.pt models/Koto/checkpoints/koto_1.3.1_large/
PYTHONPATH=src python scripts/engine/generate.py --profile models/Koto/configs/release/koto_1.3.1.yaml --prompt "Hi! Who are you?"

The release profile checks the checkpoint's SHA-256 before use. In this mode Koto gets the safety layer, the rewriting-task router, informal-text normalisation and candidate reranking.

4 · Verify and train

For developers 
pytest -q                                                    # engine tests
(cd models/Koto && python -m pytest -q tests)                # Koto tests
PYTHONPATH=src python scripts/engine/validate_release.py --profile models/Koto/configs/release/koto_1.3.1.yaml --quiet
cd models/Koto && python training/train.py --train-config configs/training/koto_1.3.1_large.yaml

Training needs the processed dataset data/processed_1.3.0; train.py refuses to start if its fingerprint does not match the config.
